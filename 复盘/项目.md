## 一、项目整体结构

目前学习到的基本请求流程：

```text
前端
  ↓
HTTP 请求
  ↓
Controller
  ↓
Service
  ↓
Mapper
  ↓
MyBatis-Plus
  ↓
MySQL
```

各层职责：

- Controller：接收 HTTP 请求、返回数据
- Service：处理业务逻辑
- Mapper：负责数据库操作
- MyBatis-Plus：提供通用 CRUD 能力
- MySQL：真正存储数据

------

# 二、@Service

```
@Service
public class UserService {
}
```

`@Service` 的作用：

> 告诉 Spring：UserService 是一个业务层组件，由 Spring 管理。

项目启动后：

```
Spring 发现 @Service
↓
创建 UserService 对象
↓
发现 Controller 需要 UserService
↓
自动注入
```

------

# 三、依赖注入 DI

Controller：

```
private final UserService userService;

public TestController(UserService userService) {
    this.userService = userService;
}
```

这里的：

```
this.userService = userService;
```

就是把 Spring 提供的 UserService 保存下来。

这叫：

> Dependency Injection，依赖注入。

不用自己：

```
new UserService()
```

而是让 Spring 创建和管理对象。

# 四、Service 中的查询 → 判断 → 修改 → 更新

今天实际写了完整的用户修改流程：

```
public UserEntity updateUser(Long id, UpdateUserQuest request) {

    UserEntity user = userMapper.selectById(id);

    if (user == null) {
        throw new RuntimeException("用户不存在");
    }

    user.setName(request.getName());
    user.setAge(request.getAge());

    userMapper.updateById(user);

    return user;
}
```

整个流程：

```
① 查询用户
      ↓
② 判断用户是否存在
      ↓
③ 修改 UserEntity 对象
      ↓
④ 更新数据库
```

------

## 4.1 查询

```
UserEntity user = userMapper.selectById(id);
```

根据 ID 查询用户。

------

## 4.2 判断

```
if (user == null) {
    throw new RuntimeException("用户不存在");
}
```

如果查询不到用户：

```
user == null
↓
用户不存在
↓
报错
```

------

## 4.3 修改 Java 对象

```
user.setName(request.getName());
user.setAge(request.getAge());
```

这里是：

```
Request
↓
取出前端传来的数据
↓
放进 UserEntity
```

例如前端：

```
{
  "name": "王五",
  "age": 28
}
```

执行：

```
user.setName(request.getName());
user.setAge(request.getAge());
```

之后 UserEntity 里的数据变成：

```
name = 王五
age = 28
```

注意：

> 此时只是修改了 Java 内存中的对象，还没有真正更新数据库。

------

## 4.4 更新数据库

```
userMapper.updateById(user);
```

这一步才是真正执行数据库更新。

可以理解成：

```
setName()
setAge()
↓
修改 Java 对象

updateById()
↓
真正更新 MySQL
```

# 六、MyBatis-Plus

UserMapper：

```
@Mapper
public interface UserMapper extends BaseMapper<UserEntity> {
}
```

重点：

```
extends BaseMapper<UserEntity>
```

因为继承了 `BaseMapper`，所以 MyBatis-Plus 已经提供了很多通用数据库操作。

因此很多简单 CRUD：

> 不需要自己写查询方法和 SQL。

# 八、selectById 和 selectList

一定要区分：

```
userMapper.selectById(id);
```

↓

> 根据 ID 查一个。

而：

```
userMapper.selectList(null);
```

↓

> 查全部。

例如数据库：

```
id    name
1     王五
2     张三
3     李四
```

执行：

```
selectById(2L)
```

得到：

```
张三
```

只有一个。

而：

```
selectList(null)
```

得到：

```
王五
张三
李四
```

# 九、QueryWrapper

如果不仅仅是查询全部，而是需要：

> 带条件查询

可以使用：

```
QueryWrapper<UserEntity> wrapper = new QueryWrapper<>();
```

例如：

```
wrapper.gt("age", 18);

return userMapper.selectList(wrapper);
```

意思：

```
age > 18
```

可以理解成 SQL：

```
SELECT * FROM user WHERE age > 18;
```

------

# 十、QueryWrapper 条件

目前学习了：

| 方法 | SQL  | 含义     |
| ---- | ---- | -------- |
| `gt` | `>`  | 大于     |
| `lt` | `<`  | 小于     |
| `eq` | `=`  | 等于     |
| `le` | `<=` | 小于等于 |

------

## 1. 大于

```
wrapper.gt("age", 18);
```

相当于：

```
age > 18
```

------

## 2. 小于

```
wrapper.lt("age", 30);
```

相当于：

```
age < 30
```

------

## 3. 等于

```
wrapper.eq("age", 30);
```

相当于：

```
age = 30
```

------

## 4. 小于等于

```
wrapper.le("age", 30);
```

相当于：

```
age <= 30
```

# 十一、今天实际完成的条件查询

查询年龄大于 18 岁：

```
public List<UserEntity> getAdultUsers() {

    QueryWrapper<UserEntity> wrapper = new QueryWrapper<>();

    wrapper.gt("age", 18);

    return userMapper.selectList(wrapper);
}
```

查询年龄小于等于 30 岁：

```
public List<UserEntity> getUsersAgeLessOrEqual30() {

    QueryWrapper<UserEntity> wrapper = new QueryWrapper<>();

    wrapper.le("age", 30);

    return userMapper.selectList(wrapper);
}
```

# 十四、今天的面试题

## 1. Service 层主要负责什么？

Service 是业务层，主要负责处理业务逻辑，并根据业务需要调用 Mapper 操作数据库。

------

## 2. 为什么修改用户前要先查询？

先确认用户是否存在，避免对不存在的数据进行修改。

------

## 3. Service 中常见的业务处理流程是什么？

```
查询
↓
判断
↓
处理
↓
更新/保存
```

------

## 4. MyBatis-Plus 为什么不用自己写很多 CRUD 方法？

因为 Mapper 继承了 `BaseMapper`，MyBatis-Plus 已经提供了很多通用的数据库操作方法。

------

## 5. selectById 和 selectList 有什么区别？

```
selectById(id)
→ 根据 ID 查询

selectList(...)
→ 查询列表
```

------

## 6. QueryWrapper 是干什么的？

QueryWrapper 用来构造数据库查询条件。

例如：

```
wrapper.gt("age", 18);
```

表示：

```
age > 18
```
