# 一、QueryWrapper 是干什么的？

`QueryWrapper` 用来**构建数据库查询条件**。

例如：

```
QueryWrapper<UserEntity> wrapper = new QueryWrapper<>();

wrapper.gt("age", 18);
```

相当于 SQL：

```
WHERE age > 18
```

然后交给 Mapper：

```
userMapper.selectList(wrapper);
```

最终就是：

```
Controller
    ↓
Service
    ↓
QueryWrapper
    ↓
Mapper
    ↓
MySQL
```

# 二、比较条件

## 1. 等于：eq

```
wrapper.eq("age", 18);
```

对应：

```
WHERE age = 18
```

## 2. 不等于：ne

```
wrapper.ne("age", 18);
```

对应：

```
WHERE age <> 18
```

记忆：

```
eq = equal = 等于
ne = not equal = 不等于
```

## 3. 大于：gt

```
wrapper.gt("age", 18);
```

对应：

```
WHERE age > 18
```

`gt`：

```
greater than
大于
```

## 4. 大于等于：ge

```
wrapper.ge("age", 18);
```

对应：

```
WHERE age >= 18
```

`ge`：

```
greater than or equal
大于等于
```

## 5. 小于：lt

```
wrapper.lt("age", 30);
```

对应：

```
WHERE age < 30
```

## 6. 小于等于：le

```
wrapper.le("age", 30);
```

对应：

```
WHERE age <= 30
```

## 7. 比较条件总表

| Java | SQL  | 含义     |
| ---- | ---- | -------- |
| `eq` | `=`  | 等于     |
| `ne` | `<>` | 不等于   |
| `gt` | `>`  | 大于     |
| `ge` | `>=` | 大于等于 |
| `lt` | `<`  | 小于     |
| `le` | `<=` | 小于等于 |

# 三、LIKE 模糊查询

## 1. like：包含

```
wrapper.like("name", "王");
```

对应：

```
WHERE name LIKE '%王%'
```

意思：

> 名字中包含“王”。

例如：

```
王五
小王
王小明
```

都可能查到。

## 2. notLike：不包含

```
wrapper.notLike("name", "王");
```

对应：

```
WHERE name NOT LIKE '%王%'
```

意思：

> 名字中不包含“王”。

## 3. likeLeft：结尾匹配

```
wrapper.likeLeft("name", "王");
```

对应：

```
WHERE name LIKE '%王'
```

意思：

> 名字以“王”结尾。

例如：

```
小王
老王
```

## 4. likeRight：开头匹配

```
wrapper.likeRight("name", "王");
```

对应：

```
WHERE name LIKE '王%'
```

意思：

> 名字以“王”开头。

例如：

```
王五
王小明
```

## 5. LIKE 总结

```
like       → %王% → 包含王
likeLeft   → %王  → 结尾是王
likeRight  → 王%  → 开头是王
notLike    → 不包含王
```

# 四、范围查询 between

```
wrapper.between("age", 20, 30);
```

对应：

```
WHERE age BETWEEN 20 AND 30
```

注意：

> `between` 两边都是包含的。

也就是：

```
20 ≤ age ≤ 30
```

20 和 30 都会被包含。

# 五、IN 和 NOT IN

## 1. IN

```
wrapper.in("id", ids);
```

例如：

```
List<Long> ids = List.of(1L, 3L, 5L);
```

相当于：

```
WHERE id IN (1, 3, 5)
```

意思：

> 只查询 ID 是 1、3、5 的用户。

## 2. NOT IN

```
wrapper.notIn("id", ids);
```

相当于：

```
WHERE id NOT IN (1, 3, 5)
```

意思：

> 排除 ID 为 1、3、5 的用户。

# 六、NULL 判断

## 1. IS NULL

```
wrapper.isNull("age");
```

对应：

```
WHERE age IS NULL
```

意思：

> 年龄为空。

## 2. IS NOT NULL

```
wrapper.isNotNull("age");
```

对应：

```
WHERE age IS NOT NULL
```

意思：

> 年龄不为空。

## 注意

SQL 中不能这样判断：

```
age = NULL
```

应该使用：

```
age IS NULL
```

或者：

```
age IS NOT NULL
```

# 七、多个条件默认是 AND

例如：

```
wrapper.gt("age", 18);
wrapper.eq("name", "王五");
```

默认相当于：

```
WHERE age > 18
AND name = '王五'
```

也就是说：

> QueryWrapper 连续添加多个条件时，默认是 AND。

# 八、OR

如果需要 OR：

```
wrapper.gt("age", 40);
wrapper.or();
wrapper.eq("name", "王五");
```

相当于：

```
WHERE age > 40
OR name = '王五'
```

# 九、AND + OR + 括号

这是今天比较重要的知识点。

需求：

> 年龄大于 20，并且名字是王五或者李四。

SQL：

```
WHERE age > 20
AND (name = '王五' OR name = '李四')
```

Java：

```
wrapper.gt("age", 20);

wrapper.and(w ->
        w.eq("name", "王五")
         .or()
         .eq("name", "李四")
);
```

# 十、这里出现的新知识：Lambda

之前没有学过 Lambda，所以这里单独记录。

## 最简单的 Lambda

```
x -> x + 1
```

可以理解成：

```
输入 x
 ↓
执行 x + 1
 ↓
得到结果
```

其中：

```
x  → 输入参数
-> → 对这个参数进行操作
```

## 在 QueryWrapper 中

看到：

```
w -> w.eq("name", "王五")
```

可以理解成：

```
传进来一个 w
↓
对 w 调用 eq()
```

这里的 `w` 只是变量名，并不是固定写法。

例如：

```
wrapper.and(x -> x.eq("name", "王五"));
```

也是可以的。

甚至可以写：

```
wrapper.and(wrapper2 -> wrapper2.eq("name", "王五"));
```

只是实际开发中通常写成：

```
w
```

比较简洁。

# 十一、排序

## 1. 升序

```
wrapper.orderByAsc("age");
```

对应：

```
ORDER BY age ASC
```

意思：

> 年龄从小到大。

## 2. 降序

```
wrapper.orderByDesc("age");
```

对应：

```
ORDER BY age DESC
```

意思：

> 年龄从大到小。

记忆：

```
Asc  → Ascending  → 升序 → 小 → 大

Desc → Descending → 降序 → 大 → 小
```

# 十二、分页查询

如果数据库有 10000 个用户：

```
第1页 → 10条
第2页 → 10条
第3页 → 10条
...
```

不能一次全部查询出来。

所以需要分页。

## 1. 创建 Page

```
Page<UserEntity> page = new Page<>(3, 20);
```

表示：

```
第 3 页
每页 20 条
```

## 2. 执行分页查询

```
userMapper.selectPage(page, null);
```

这里：

```
null
```

表示：

> 不添加额外查询条件。

## 3. 获取当前页数据

```
page.getRecords()
```

表示：

> 获取当前页真正查询出来的数据。

# 十三、分页 + QueryWrapper

两者可以结合。

例如：

> 第 2 页，每页 10 条，只查询年龄大于 18 岁的用户。

```
Page<UserEntity> page = new Page<>(2, 10);

QueryWrapper<UserEntity> wrapper = new QueryWrapper<>();
wrapper.gt("age", 18);

userMapper.selectPage(page, wrapper);

return page.getRecords();
```

理解成：

```
Page
 ↓
决定查第几页、每页多少条

QueryWrapper
 ↓
决定查询什么条件

selectPage()
 ↓
执行查询

getRecords()
 ↓
拿到当前页的数据
```

